# Exploratory-Data-Analysis-of-Diwali-Sales-Trends
This project explores customer behavior and purchasing patterns to derive actionable business insights using Python (Pandas, Matplotlib, Seaborn) and visualizes them in an interactive Streamlit dashboard.

Technologies Used:

            -Python

            -Pandas, NumPy

            -Matplotlib, Seaborn

            -Jupyter Notebook

            -Streamlit

            -CSV for data storage


Through exploratory data analysis, we identified:

            -Top-performing products and most valuable customers

            -Spending behavior patterns by gender, age group, and location

            -Key contributing states to overall sales
