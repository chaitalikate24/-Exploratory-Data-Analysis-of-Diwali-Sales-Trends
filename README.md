# Exploratory-Data-Analysis-of-Diwali-Sales-Trends
This project explores customer behavior and purchasing patterns to derive actionable business insights using Python (Pandas, Matplotlib, Seaborn) and visualizes them in an interactive Streamlit dashboard.

Technologies Used:

            -Python

            -Pandas, NumPy

            -Matplotlib, Seaborn

            -Jupyter Notebook

            -Streamlit

            -CSV for data storage
